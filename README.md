# banana_dock · 车机悬浮 Dock

跑在安卓 9（API 28）车机上的悬浮 Dock。当前版本 **3.13.49**（versionCode 370）。

- 包名：`com.car.dockbar`
- 屏幕按 **1920 × 1080、DPI 160**（1dp = 1px）写死，不读系统显示参数
- 窗口默认 **1920 × 128 px**，贴底。y = 1080 − 128 − 距边 0 = **952**
- 车控走反射，编译期不依赖厂商 jar
- 歌曲走通知使用权里的 **MediaSession**。`com.flyme.auto.music` 没有会话时再读它的通知

---

## 一、默认布局

宽度不再按 18 个等宽槽切。固定项锁死像素，只剩音乐卡弹性伸缩（295～500px）。1920 宽时音乐卡是 **336px**。

| 顺序 | 控件 | 宽 px |
| --- | --- | --- |
| D01 | 返回桌面 | 98 |
| D02 | 音乐信息 | 336（弹性） |
| D03 | 歌词悬浮窗 | 98 |
| D04 | 车机设置 | 98 |
| D05 | 快捷应用 | 98 |
| D06 | 主驾温度 − 值 + | 290 |
| D12 | 空调风向 | 98 |
| D13 | 主驾座椅通风 | 98 |
| D08 | 风速 − 值 + | 220 |
| D18 | 内外循环 | 98 |
| D19 | 座椅 | 98 |
| D07 | 副驾温度 − 值 + | 290 |

固定项合计 1584，加上音乐卡 336 = 1920。

图标默认 **65px**（返回桌面圆环是 0.8 倍）。风速组合里的 ± 箭头是 **40px**。1 槽项 98px，温度组合 290px，风速组合 220px。圆角默认 **14px**。

前挡加热、后挡除霜、方向盘加热、座椅加热默认不在栏上，要在「Dock 条目」里手动加。

## 二、控件行为

| 控件 | 单击 | 长按 |
| --- | --- | --- |
| 返回桌面 | 回桌面 | 双击打开最近任务 |
| 音乐卡 | 打开当前播放器 | — |
| 音乐卡播放键 | 播放 / 暂停 | 下一曲 |
| 歌词 | 开 / 关歌词悬浮窗 | 打开本应用 |
| 车机设置 | 打开设置 | — |
| 快捷应用 | 打开 2×3 面板 | 去设置里选这 6 个应用 |
| 主驾温度 ± | 温度 ±0.5℃ | — |
| 主驾温度数字 | 温度弹窗 | 切换 AC |
| 副驾温度 ± | 温度 ±0.5℃ | — |
| 副驾温度数字 | 温度弹窗 | 切换双温同步 |
| 风向 | 风向弹窗 | 打开空调 |
| 座椅通风 | 降档（关时跳到 3） | 升档（3 档再按关） |
| 风速 ± | 手动 0～9；AUTO 开着时改 AUTO 1～5 | — |
| 风速数字 | 开 / 关 AUTO | 关风速 |
| 内外循环 | 内 / 外切换 | — |
| 座椅 | 座椅弹窗 | — |

Dock 被应用名单藏起来之后，底部小横条上滑临时唤出。倒计时从松手、弹窗关掉之后才开始，默认 5 秒。

## 三、外观

四选一：纯色、透明、渐变、毛玻璃。

纯色模式下，只有系统桌面（`com.android.launcher3` 或当前默认 HOME）在前台时，底色自动改成透明。其它应用在前台仍是纯色。

---

## 四、车控通道

温度不是旧文档里的「索引 × 0.5」。int 通道低 8 位 = `round(℃ / 0.2)`，可调 **15.5～28.5℃**，步进 0.5。zone 用座椅位：主驾 **1**，副驾 **4**。

| 功能 | functionId | zone | 取值 |
| --- | --- | --- | --- |
| 手动风量 | `0x10020100` | `0x8` | 复合编码 0～9 档 |
| AUTO 风量 | `0x10020200` | `0x8` | 1～5 档，低字节乱序：1→`0x04`，2→`0x01`，3→`0x02`，4→`0x03`，5→`0x05` |
| AUTO 总开关 | `0x10010200` | `0x80000000` | 裸值 0 / 1 |
| 主驾温度 | `0x10060100` | `1` | `round(℃ / 0.2)` |
| 副驾温度 | `0x10060100` | `4` | 同上 |
| 双温同步 | `0x10060500` | `0x80000000` | 0 / 1 |
| AC | `0x10010300` | `0x80000000` | 0 / 1 |
| 风向 | `0x10070100` | `0x8` | 复合编码 1～7 |
| 内外循环 | `0x10030100` | `0x80000000` | 外循环裸值 0，内循环 `0x10030101` |
| 主驾座椅通风 | `0x10050100` | `1` | 0～3 |
| 主驾座椅加热 | `0x10050200` | `1` | 0～3 |
| 副驾座椅通风 | `0x10050100` | `4` | 0～3 |
| 副驾座椅加热 | `0x10050200` | `4` | 0～3 |
| 方向盘加热 | `0x10090100` | `1` | 0～3 |
| 前挡加热 | `0x10040100` | 全局 | 开关 |
| 后挡除霜 | `0x10040300` | 全局 | 开关 |

座椅通风不是 `0x10050000`，座椅加热不是 `0x10050100`。循环和 AUTO、AC、双温同步的 zone 是整车 `0x80000000`，不是 `0x8`。

AUTO 打开时，风速 ± 写 `0x10020200`，不写手动风量。

## 五、音乐

先绑活跃 MediaSession。歌名、歌手、播放状态从会话读。

封面按这个顺序取：会话里的位图、`ALBUM_ART_URI` 一类本地路径或 `content://`、播放器通知上的大图。酷狗车机版（`com.kugou.android.auto`）经常只有歌名没有位图，封面在它自己的通知大图里。

`com.flyme.auto.music` 不进活跃会话。系统那条「QQ音乐正在运行」不当成歌曲。有真实歌名的通知才用。

---

## 六、设置页

左侧：悬浮 Dock 栏、外观、Dock 条目、歌词、常驻应用、诊断。

悬浮 Dock 栏右侧有宽、高、距边。高的默认值是 **128**。原来存成 120 的会在第一次读取时改成 128。

还要开悬浮窗权限、通知使用权、前台应用检测。前台检测用来决定哪些应用藏 Dock，也用来判断是不是系统桌面。

---

## 七、编译

JDK 用 Android Studio 自带的 JBR。`JAVA_HOME` 指到 `C:\Program Files\Android\Android Studio\jbr`。系统里的 Java 8 编不过。

```bash
.\gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/CarDockBar-release.apk`。
